# 赛题分析报告：绿电直连型电氢氨园区优化运行

## 一、赛题概述

### 1.1 背景

本题研究绿电直连型电氢氨园区的优化运行问题。园区通过风电（40MW）和光伏（64MW）直连供电，驱动碱性电解槽（ALKEL）和质子交换膜电解槽（PEMEL）制氢，再通过合成氨装置将氢气转化为氨。园区与外部电网相连，可购电补充不足、余电上网售出，需满足国家绿电直连项目的三项指标要求。

### 1.2 核心约束（绿电直连指标）

- **自发自用比** = (总用电量 − 上网电量 − 网购电量) / 新能源发电量 > 60%
- **绿电比例** = (新能源发电量 − 上网电量) / 总用电量 > 30%
- **上网比例** = 上网电量 / 新能源发电量 < 20%

### 1.3 子问题数量

**本赛题共 5 个子问题**（问题一至问题五），其中问题一至四为定量建模求解，问题五为定性分析。

### 1.4 子问题递进关系

```
问题一（基准分析）→ 问题二（离散调节优化）→ 问题三（连续调节优化）→ 问题四（离网+储能）→ 问题五（政策分析）
       ↓                    ↓                      ↓                    ↓
  满负荷运行            产能可调(离散)          产能可调(连续)        完全自给
  36吨/日              72→36吨/日             72→36吨/日           72吨/日+储能
  指标分析             成本最优调度            成本最优调度          储能配置优化
```

## 二、子问题拆解

### 问题一：典型风光场景下绿电直连指标分析

**难度：简单**

**输入：**
- 附件1（常规负荷标幺曲线）、附件2（典型日风光标幺曲线）
- 设备参数：碱性电解槽10MW/140kg·H₂/h，PEMEL 10MW/160kg·H₂/h，合成氨0.75MW/1.5t·NH₃/h
- 制氨产能36吨/日，满负荷连续运行

**输出：**
- (1) 功率曲线图（用电负荷、风光发电、购电、售电）
- (2) 各项电量指标、绿电直连三项指标、吨氨成本

**方法：** 功率平衡计算 + 分时电价成本核算

**关键发现（预计算）：**
- 总用电量：558.72 MWh/日，新能源发电量：603.45 MWh/日
- 自发自用比 ≈ 28.16%（**不满足** >60%要求）
- 绿电比例 ≈ 69.21%（满足 >30%要求）
- 上网比例 ≈ 35.92%（**不满足** <20%要求）
- 原因：风光出力与负荷时间不匹配，白天光伏大量余电上网，夜间需大量购电

### 问题二：基于离散制氨调节的运行优化

**难度：中等**

**输入：**
- 产能扩至72吨/日（设备功率线性扩容：碱性20MW，PEMEL 20MW，合成氨1.5MW）
- 产量从72吨/日按9吨/日递减至36吨/日（共5个产量水平：72/63/54/45/36）
- 电氢氨装置只有全额开机/停机两种方式
- 附件3（6种风电场景）、附件4（4种光伏场景）→ 24种组合

**输出：**
- (1) 典型场景下每种产量的最优生产时段安排、绿电指标、最低吨氨成本产量
- (2) 24种场景下各产量最优方案、指标分布、全年统计

**方法：** 整数规划 / 枚举优化（24小时中选择开机时段，二值决策）

**关键约束：**
- 产量72吨/日 → 需运行24h（满负荷）
- 产量63吨/日 → 需运行21h（选择21个时段开机）
- 产量54吨/日 → 需运行18h
- 产量45吨/日 → 需运行15h
- 产量36吨/日 → 需运行12h
- 每个时段设备要么全开要么全关

### 问题三：基于连续制氨调节的运行优化

**难度：困难**

**输入：**
- 同问题二的产能和产量范围
- 电氢氨装置功率连续可调（下限10%）
- 24种风光场景

**输出：**
- (1) 每种场景最优调度方案、绿电指标、吨氨成本、全年统计
- (2) 各场景运行分析
- (3) 与问题二对比分析

**方法：** 线性规划 / 非线性规划（连续变量优化）

**关键特征：**
- 决策变量：每小时制氢制氨功率（连续，10%~100%额定功率）
- 目标函数：最小化吨氨成本
- 约束：日产量目标、功率上下限、绿电指标（软/硬约束）

### 问题四：离网运行及储能配置

**难度：困难**

**输入：**
- 离网运行（无外部电网）
- 产能72吨/日，功率连续可调（下限10%）
- 24种风光场景
- 储能参数（附件6）

**输出：**
- (1) 无储能时各场景产量、吨氨成本、最小风光装机容量
- (2) 最大弃电场景的储能最优配置、有储能调度方案
- (3) 离网vs联网经济性对比

**方法：** 多阶段优化（储能容量配置 + 运行调度联合优化）

**关键特征：**
- 离网约束：风光发电 ≥ 总用电（每时段）
- 储能引入时间耦合：充放电状态转移
- 储能参数：效率90%×90%=81%，自损耗0.2%/h，投资1000元/kWh

### 问题五：政策分析

**难度：简单（定性）**

**输出：** 绿电园区容量渗透率提高对电力系统的影响（≥3种利弊）+ 政策建议

**方法：** 文献综述 + 定性分析

### 3.3 问题一预计算结果

典型日满负荷运行：
- 自发自用比 = 28.16%（**严重不满足** 60%要求）
- 绿电比例 = 69.21%（满足 30%要求）
- 上网比例 = 35.92%（**不满足** 20%要求）
- 吨氨成本 ≈ 4322 元/吨

**不满足原因分析：** 风光出力集中在白天（尤其光伏10:00-16:00），而制氢制氨24h满负荷运行，导致白天大量余电上网、夜间大量购电。自发自用比公式的分子 = 总用电 − 上网 − 网购 = 新能源自用电量，当同时存在大量购电和售电时，自发自用比必然很低。

### 5.2 快速验算对比

**关于解释5（制氢耗电）：**
- 解释A：碱性实际耗电 = 50/0.7 = 71.43 kWh/kgH₂，PEMEL = 50/0.8 = 62.5 kWh/kgH₂
  - 碱性功率验证：140 kg/h × 71.43 kWh/kg = 10000 kW = 10 MW ✓
  - PEMEL功率验证：160 kg/h × 62.5 kWh/kg = 10000 kW = 10 MW ✓
- 解释B：碱性实际耗电 = 50 kWh/kgH₂
  - 碱性功率 = 140 × 50 = 7000 kW = 7 MW ≠ 10 MW ✗

**结论：** 解释A正确，"50kWh/kg未考虑效率"意味着实际耗电 = 50/η，与额定功率完全吻合。

## 六、建模思路规划

### 问题一：功率平衡直接计算

**方法：** 代数计算（无优化）

$$P_{total}(t) = P_{ALK}^{rated} + P_{PEM}^{rated} + P_{NH3}^{rated} + P_{load}(t)$$

$$P_{net}(t) = P_{wind}(t) + P_{pv}(t) - P_{total}(t)$$

$$P_{buy}(t) = \max(-P_{net}(t), 0), \quad P_{sell}(t) = \max(P_{net}(t), 0)$$

吨氨成本 = (风电成本 + 光伏成本 + 电解槽运维 + 合成氨运维 + 购电成本 − 售电收入) / 日产氨量

### 问题二：离散时段优化（整数规划）

**推荐方法：** 0-1整数规划 + 枚举

**决策变量：** $u(t) \in \{0, 1\}$，$t = 1, ..., 24$

**目标函数：** 最小化吨氨成本

$$\min \frac{\sum_{t=1}^{24} [c_{buy}(t) \cdot P_{buy}(t) - c_{sell} \cdot P_{sell}(t) + C_{RE}(t) + C_{OM}(t)]}{M_{NH3}}$$

**约束：**
- $\sum_{t=1}^{24} u(t) = T_{required}$（运行时段数 = 日产量/小时产量）
- 功率平衡：$P_{buy}(t) - P_{sell}(t) = P_{demand}(t) \cdot u(t) + P_{load}(t) - P_{RE}(t)$
- 绿电指标约束（可作为硬约束或软约束分析）

**求解策略：** 由于24小时选T个时段，组合数 $C_{24}^{T}$ 在T=12~24范围内可枚举（最大 $C_{24}^{12}$ = 2,704,156），可用穷举或分支定界。

### 问题三：连续功率优化（线性规划）

**推荐方法：** 线性规划（LP）

**决策变量：** $\alpha(t) \in [0.1, 1]$，$t = 1, ..., 24$

**目标函数：** 最小化吨氨成本

**约束：**
- 日产量约束：$\sum_{t=1}^{24} \alpha(t) \cdot m_{NH3}^{rated} = M_{target}$
- 功率平衡（同问题二但用连续变量）
- 功率下限：$\alpha(t) \geq 0.1$
- 绿电指标约束

**特点：** 目标函数和约束均为线性（购电/售电通过引入辅助变量线性化），可用scipy.linprog或PuLP求解。

### 问题四：离网储能联合优化

**推荐方法：** 两阶段优化
- 第一阶段（无储能）：LP求解各场景最大产量
- 第二阶段（有储能）：储能容量配置 + 运行调度联合优化（MILP或NLP）

**储能状态方程：**

$$E_{sto}(t+1) = E_{sto}(t) \cdot (1 - \sigma) + P_{sto,c}(t) \cdot \eta_c - P_{sto,d}(t) / \eta_d$$

**离网功率平衡：**

$$P_{wind}(t) + P_{pv}(t) + P_{sto,d}(t) = P_{demand}(t) + P_{sto,c}(t) + P_{curtail}(t)$$

**储能容量优化目标：** 最小化全年综合成本（储能投资分摊 + 运行成本）

### 问题五：定性分析框架

从以下角度分析：
- **利：** 促进新能源消纳、降低输电损耗、推动氢能产业链
